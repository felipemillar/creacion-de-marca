En esta etapa se da forma tangible a la marca. Se definen el nombre (naming) y los activos visuales y sensoriales (logo, colores, tipografía, sonido, tacto y olor) aplicando principios de diseño cognitivo, Leyes de UX y sinergia intermodal para garantizar que la identidad sea memorable y fácil de procesar.

## 👂 El Enfoque Multisensorial (Sinergia Intermodal - Lindstrom)

De acuerdo con Martin Lindstrom, el impacto de una marca en la memoria a largo plazo aumenta exponencialmente cuando se estimulan múltiples sentidos de manera coherente (congruencia semántica). No sumamos estímulos al azar; diseñamos una experiencia unificada:

1.  **Vista (Hegemonía Visual):** Diseños minimalistas gobernados por la Ley de Prägnanz (formas simples) y jerarquía visual.
2.  **Oído (Sonic Branding):** Desarrollo de firmas acústicas, logotipos sonoros o ambientes auditivos breves que refuercen la emoción de la marca (Sistema 1).
3.  **Tacto (Háptica):** El diseño de envases, texturas de papelería o peso físico de los productos que alteran inconscientemente la percepción de calidad y sabor.
4.  **Olfato (Vector Límbico):** Aromas corporativos y firmas olfativas. Al procesarse directamente en el sistema límbico sin pasar por el tálamo, el olfato tiene una capacidad de memoria hasta **10,000 veces superior** al gusto.

### Prompt 1: Cognitive Naming & Phonetic Explorer
Este prompt genera nombres comerciales optimizados para la fluidez cognitiva, clasificándolos en categorías lingüísticas clave.

```text
Act as a professional naming expert and brand linguist. I need to find a name for a new brand that maximizes cognitive fluency, domain availability potential, and emotional recall.

Inputs:
- Brand DNA & Purpose: [insert output from Phase 1]
- Target Audience Language: [e.g., Spanish, English, Bilingual]
- Niche and Core Offering: [insert offering]

Task:
1. Generate 12 name proposals classified into the following 3 categories:
   - Neologisms (invented words with intuitive meanings, e.g., Spotify, Kodak).
   - Descriptive/Metaphorical (real words that evoke a feeling or benefit, e.g., Apple, Nike).
   - Compound Words (combining two simple words, e.g., Microsoft, FaceBook).
2. Ensure all proposals meet these cognitive rules:
   - Maximum 3 syllables (ideally 2).
   - Extremely high phonetic simplicity (easy to pronounce and spell in both Spanish and English).
   - Positive emotional valence.
3. For each name, provide:
   - A 1-sentence semantic justification.
   - A pronunciation check (ease of spelling and reading).
```

### Prompt 2: Multisensorial Visual & Sonic Vibe Developer (Midjourney/DALL-E)
Este prompt traduce la esencia de tu marca en activos visuales minimalistas y define las directrices sonoras y táctiles de la marca.

```text
Act as a creative director and sensory branding architect. I need a comprehensive visual and sensory design brief for my brand.

Inputs:
- Brand Archetypes & Values: [insert output from Phase 1]
- Sensory Keywords / Mood: [e.g., organic, premium, gélido, azul, ecológico]
- Core Product/Service: [insert product]

Task:
1. Establish the "Sensory Identity Direction":
   - Visual Metaphor: Key shapes and layout constraints (applying the Law of Prägnanz).
   - Sonic Vibe: Describe a 3-second sound logo (instruments, tempo, emotional response).
   - Tactile/Haptic direction: Describe textures, materials, and weight of the packaging or touchpoints.
   - Olfactory direction: Propose a signature scent profile (notes, feelings) that bypasses the thalamus.
2. Generate 3 detailed prompts in English for AI image generators (like Midjourney or DALL-E) to create visual assets:
   - Prompt A (Logo Concept): A minimalist, geometric logo design with clean vector shapes, vector icon, white background --style raw.
   - Prompt B (Brand Photography / Mood): A photographic scene depicting the brand's lighting style, materials, and color palette in context.
   - Prompt C (Digital UI context): A high-fidelity mobile or web mockup showing clean layout, hierarchy, and accent color placement.
```

### Prompt 3: Typography & Cognitive Color Palette Designer
Este prompt diseña el sistema cromático y tipográfico optimizado para la usabilidad, contraste y jerarquía visual.

```text
Act as a lead UI designer and color psychologist. I need to establish the color palette and typography rules for my brand to optimize reading fluency and visual hierarchy.

Inputs:
- Brand Archetype: [insert primary archetype]
- Core Digital Touchpoint: [e.g., B2B dashboard, e-commerce landing page]

Task:
1. Define a "Cognitive Color Palette" based on the 60-30-10 Rule:
   - Dominant Color (60% weight, sets the emotional tone, e.g., Deep Navy Blue for security).
   - Supporting Color (30% weight, structures layout and background, e.g., Soft Off-White).
   - Accent Color (10% weight, reserved strictly for CTAs and conversion elements to trigger Fitts' Law, e.g., Vibrant Orange).
2. Select a typography pairing (Primary Font for headers, Secondary Font for body text) using highly legible web fonts (e.g., Google Fonts). Explain how they reduce visual fatigue.
3. Create 3 visual usability rules:
   - Minimum font size for mobile interfaces.
   - Minimum contrast ratio target (applying WCAG 2.1 AA).
   - Visual padding and alignment rules based on the Law of Common Region.
```

## 📋 Checklist de Neuro-Estética (Fase 3)

Audita los entregables de diseño visual y sensorial con este checklist de usabilidad y percepción.

### Validación Cualitativa (Autoevaluación)
*   [ ] **Ley de Prägnanz (Simplicidad):** ¿El logotipo tiene una silueta simple y contornos cerrados? ¿Es recordable tras verlo solo 5 segundos?
*   [ ] **Sinergia Intermodal:** ¿Los estímulos visuales, sonoros y táctiles propuestos son congruentes con el arquetipo primario de la Fase 1?
*   [ ] **Regla del 60-30-10:** ¿La paleta de colores respeta la jerarquía cromática para evitar saturar el Sistema 1 visual del usuario?
*   [ ] **Fluidez del Naming:** ¿El nombre es corto, fonéticamente simple y se deletrea igual que como suena en español e inglés?

### Validación Cuantitativa y Métricas Sugeridas
*   **Ratio de Contraste WCAG:** Utiliza un validador de contraste de color. El texto debe tener un ratio mínimo de **4.5:1** contra el fondo para texto estándar, y de **3:1** para elementos gráficos o botones de conversión.
*   **Test del Borroso (Blur Test):** Aplica un desenfoque alto al diseño de tu página o logotipo. ¿Siguen destacando visualmente la llamada a la acción (CTA) y el icono del logo? Si el color de acento se diluye, ajusta el tamaño o el contraste.
*   **Filtro Háptico:** Si produces un empaque físico, pesa el producto. Los empaques ligeramente más pesados activan marcadores somáticos de *"premium/calidad"* en el Sistema 1, mientras que los plásticos ultra-ligeros evocan *"barato/descartable"*.
