Efecto Colapsable de Logo Anthropic

Una recreación interactiva y de alta fidelidad del logotipo que se contrae suavemente de "ANTHROP\C" a "A\" al hacer scroll hacia abajo.

Haz Scroll hacia abajo para ver el efecto
Interactúa con el Efecto

El secreto del efecto de Anthropic reside en dividir el logo en partes estáticas (las que siempre son visibles) y partes colapsables. Al hacer scroll, la propiedad max-width de las letras colapsables se reduce a 0 y su opacidad cae a 0. La transición se suaviza utilizando una curva de aceleración cubic-bezier(0.25, 1, 0.5, 1). 

<!-- El logotipo se divide en caracteres fijos y grupos colapsables -->
<a href="#" class="logo-container">
  <span class="logo-always">A</span>
  <span class="logo-collapsible">NTHROP</span>
  <span class="logo-always logo-slash">\</span>
  <span class="logo-collapsible">C</span>
</a>
/* --- Estilos del Logotipo --- */
.logo-container {
  display: inline-flex;
  align-items: center;
  font-family: 'Outfit', sans-serif;
  font-weight: 800;
  font-size: 2.2rem;
  text-decoration: none;
  color: #ffffff;
  transition: all 0.5s cubic-bezier(0.25, 1, 0.5, 1);
}

/* Letras estáticas (A y \) */
.logo-always {
  color: #e0d0c0; /* Color beige */
  transition: all 0.5s cubic-bezier(0.25, 1, 0.5, 1);
}

/* Grupos de letras colapsables (NTHROP y C) */
.logo-collapsible {
  display: inline-block;
  max-width: 250px; /* Ancho máximo suficiente para el texto */
  opacity: 1;
  overflow: hidden;
  white-space: nowrap;
  
  /* Curva cubic-bezier para lograr una contracción "buttery-smooth" */
  transition: max-width 0.6s cubic-bezier(0.25, 1, 0.5, 1), 
              opacity 0.4s ease, 
              transform 0.6s cubic-bezier(0.25, 1, 0.5, 1);
  transform: scaleX(1);
  transform-origin: left center;
}

/* --- Estado Colapsado (Activado en scroll) --- */
header.scrolled .logo-collapsible {
  max-width: 0;
  opacity: 0;
  transform: scaleX(0); /* Contracción adicional en escala horizontal */
}
// Seleccionamos el header
const header = document.getElementById('main-header');

// Escuchamos el evento de scroll en la ventana
window.addEventListener('scroll', () => {
  // Si bajamos más de 50px, agregamos la clase .scrolled, si no la removemos
  if (window.scrollY > 50) {
    header.classList.add('scrolled');
  } else {
    header.classList.remove('scrolled');
  }
});
