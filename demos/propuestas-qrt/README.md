# Tres propuestas visuales para qrt

Abrir `index.html` en un navegador. El selector superior permite recorrer las tres propuestas; también funcionan como archivos locales.

- `index.html`: ingeniería editorial. Fondo claro, arquitectura explicada y servicios organizados en filas.
- `laboratorio.html`: laboratorio interactivo. Fondo oscuro, diagrama explorable y etapas de datos, investigación, ejecución y monitoreo.
- `institucional.html`: confianza institucional. Paleta cálida, tipografía editorial, ilustración arquitectónica y contenido según perfil de cliente.

Los textos son propuestas para evaluar, no un catálogo comercial aprobado. No se incluyen clientes, resultados ni certificaciones inventados. No se modifican las páginas principales del sitio.

Los botones de conversación abren un formulario local que genera un resumen copiable. No hay envío de datos, integración con CRM ni backend. Las fuentes tipográficas se solicitan a Google Fonts y tienen alternativas locales.

Las tres páginas incluyen estilos para móvil, navegación por teclado, enlaces de salto y reducción de movimiento según la preferencia del sistema. La página institucional permite recorrer las pestañas con las flechas, Inicio y Fin.
